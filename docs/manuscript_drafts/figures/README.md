# Manuscript figures

Filenames match the current manuscript numbering. They did not always: several files
still carried numbers from an earlier draft, so `fig_3_4_combined.png` was the
pass-rate/domain figure rather than anything to do with Figure 3, and
`fig_1_2_combined.png` was Figure 1. Anyone assembling the manuscript had to know that
from memory. This table replaces that memory.

No draft references a filename; the prose cites "Figure 1" and so on. So renaming files
is safe, and keeping this table current is the only thing preventing the drift from
recurring.

Kept for provenance, not for use.

| File | Why |
|---|---|
| `fig_2_sankey_dataset_flow.*` | Drew the discovery sources as a partition, which cannot show their overlap; replaced by the Venn in Figure 1B. Its source counts were also hardcoded constants that no longer matched the data. |

| `fig_3b_fork_rate_absolute.*` | Counted months before a repository's first commit as zero-fork months. Because 280 of the 614 license adopters were under a year old at their event, 11% of pre-event month-cells were pre-birth zeros, concentrated in the earliest months, which manufactured an upward pre-trend that is not in the data. Its placebo was also a random date in the same repository, which sits later in the lifecycle than a license addition and so opens at more than double the fork rate. Replaced by `fig_3b_matched_did_forks`. |
